# 宿主 UI 接入

宿主视觉使用固定标签凝光 1.4.4 的公开 API，`lumen-engine` 与 `lumen-motion` 由同一正式标签的复合构建提供。`hook/feature` 只负责能力发现、Hook 安装和运行时诊断，具体 UI 装配放在本目录。模块自己的设置界面仍在 `ui/activity`；宿主视觉代码不再依赖那里的材质或导航实现。

| 模块 | 宿主职责 | 引擎接口 |
| --- | --- | --- |
| `common` | 读取宿主换肤、寻找独立内容层、管理注入区域生命周期、适配帧时钟 | `LumenPalette`、`LumenSurfaceSession`、`LumenSurfaceBinding`、`LumenSurfaceLegibilityController`、`LumenSpring`、`TouchGlowRenderer` |
| `top` | 原生分类布局、收岛输入与刷新/回顶、列表占位、融合带位置 | 局部采样表面、自定义形状输入、渐隐预设、弹簧与柔光 |
| `bottom` | 原生标签槽位、隐藏项、发布入口、拖动落点与点击转交 | 浮动与选中表面、弹簧与柔光 |
| `cards` | 列表识别、播放器排除、封面轮廓、信息区间距与坐标裁剪 | `LumenFluentControl` 共享亚克力场、CARD 层级与静态表面 |
| `follow` | 关注页标题、卡片排布、选中项、复用与状态栏位置 | 局部表面会话、`LumenSlidingSelection`、线性渐隐扩展 |
| `overlays` | 复制气泡的定位、独立文字层与选择时机、回复脉络的背景透明度和关闭释放 | `BubbleDrawable`、`LumenEasing`、静态表面会话 |

## 表面与生命周期

顶栏、底栏的视觉参数集中在 `common/HostSurfaceStyle.kt`，关注页参数在 `follow/FollowFeedStyle.kt`。新增外观优先调整公开 options/preset，不引入本地 Shader、位图模糊、NinePatch 阴影或自绘材质 Drawable，也不引用引擎 `internal` 类型。

`HostSurfaceScope` 为每个注入区域持有局部会话。每个 Drawable 只由它所绑定的 View 持有；收岛外壳使用独立的真实 View，不把 dock 的背景搬到输入层 Canvas。采样源必须是独立内容层，排除自身、祖先和注入装饰。宿主布局、padding、文字与点击行为由适配层保留。

区域 detach 时关闭会话与图形资源，重新 attach 时重建绑定；宿主覆盖背景时重新绑定，关闭时仅恢复本会话仍持有的背景。配色来自宿主 `NightTheme` 和 `ThemeUtils`，反射入口只在装配时解析。位置变化通过 `notifyPositionChanged` 通知引擎，形状输入按几何变化更新，避免逐帧重建 Drawable。

第三方 Activity 不调用 `LumenActivityDelegate.prepare` 或 `bindRoot`，局部表面不读取引擎偏好、不接管宿主窗口。复制气泡拥有自己的 Dialog，使用公开 `BubbleDrawable` 绘制外壳；适配层保留原来的按文字限宽布局、顶部箭头、底部 20% 安全区与独立文字淡入，200ms 入场、150ms 离场、120/100ms 描边淡入淡出。1.2.0 的默认 presenter 会改变宽度和文字运动，所以不用于此处。关闭开始时交还触摸，销毁 owner 时关闭 Dialog 并注销会话回调。回复脉络面板的会话随其原有 controller 释放，透明度仅影响填充色，描边保留原不透明度。

顶栏弹簧参数与原实现一致：收起刚度 115、阻尼比 0.84；展开 88 / 0.68；按压反馈 420 / 0.8。`HostSpringAxis` 只适配帧时钟和重定向，把原参数传给引擎；静止判据保留位置容差与 20 倍速度容差。60/90/120Hz 回归直接比较迁移后的轨迹与原算法，覆盖收尾、过冲和带速度反转。回复面板使用原 standard 曲线，保持 180/150ms 进退场与 160ms 回复树淡入。

深色栏通过引擎公共可读性扩展保留原 8Hz 亮度/细节统计、宿主灰色前景对比度补偿、0.92 色罩上限、迟滞和 240ms 过渡。采样区域来自绑定的实际形状，随会话、内容层与主题变化释放或重建；亮色和静态选中项不启用探针。白色渐变描边、原色罩强度、采样层独立 alpha 和采样失败时的半透明回退均通过公开参数声明。

`HostOverlaySurfaces` 还处理静态面板从零 alpha 恢复可见的绘制刷新：1.2.0 在零 alpha 时跳过背景，而 Android 属性动画可能复用该空白硬件绘制缓存。适配层只在恢复可见的那一帧 invalidate，不增加逐帧采样，并在关闭时移除观察器。更新引擎时保留真实窗口 PixelCopy 回归，确认上游修复后再去掉适配。

“卡片亚克力效果”是独立开关，默认关闭，依赖“视频卡片悬浮美化”，重启宿主后生效。关闭时不建立亚克力采样会话，沿用原有静态表面。开启后，原生视频列表、追番/影视 Compose 海报、动态外层分组与引用卡片共用 `HostCardAcrylicScope`：每个视口只建立一个引擎 `LumenFluentControl`、一个采样绑定，卡片按真实窗口坐标裁剪同一材质结果，各自保留 CARD 描边、阴影与圆角。API 29 起使用共享 RenderNode，旧系统或软件 Canvas 使用 Picture；材质、噪点与模糊均由引擎绘制，不在模块重写。单视口 GPU 上限 8,388,608 像素用于容纳页面及 48dp 模糊边距，其余预算沿用引擎默认值。

采样源只绘制窗口基色和视口及祖先的真实背景，不包含封面、文字或卡片自身；源代理透明，材质目标裁掉自身输出，两者不改变布局、触摸或无障碍。壁纸版本、尺寸、主题或引擎状态失效时重录材质，位置改变仅更新裁剪矩阵。硬件 RenderNode 与软件 Picture 分别缓存，顶栏的软件取样不能替换屏幕显示列表引用的 GPU 节点，视口尺寸改变也保留节点身份。Compose 用宿主的布局坐标回调及 Snapshot 状态使绘制缓存随位置失效；各卡片使用独立 Drawable，避免共享 bounds 或 callback。原生信息区的无 id `TintView` 底板只在亚克力开启时临时透明化，离屏恢复仍由本层持有的原背景。动态暂停时释放共享场，视口 detach 时关闭会话与录制资源。低内存、省电、失焦或预算不足的回退由引擎策略处理。播放器及播放结束页继续排除；评论关系线、刷新箭头等业务图形仍由原内容 View 绘制。

UP 动态筛选页与关注页共用分组表面。9.14 的 `VideoQuickConsumeFragment` 直接持有 `gv1.c`，新家族才使用 F/E 子类；旧家族须同时核对 Fragment 的唯一同类型字段与专用 `cardBgPainter` 回调。旧缓存只有首页描述时重新补齐已知 UP 角色，不能因首页入口仍有效而永久跳过独立页面。装饰器替换仍须通过已注册页面、列表及分组身份检查。

同机八次上下滑动的对照：按 VSYNC 去重后的帧完成耗时 P95 从旧逐卡片方案 119.216ms 降至共享方案两轮 43.430/45.192ms；UI 阶段 P95 为 30.574 → 21.733/21.478ms。帧完成耗时含渲染管线等待，不能换算为 FPS；原始 framestats 环形窗口各保留 119 个不同 VSYNC，推荐内容随冷启动刷新，结果仅代表本机这组场景。首次共享缓存混用了软硬件节点，虽有更低耗时但效果不完整，该轮数据不作为优化结果；最终对照已确认实际亚克力绘制。

`background` 生成视频列表的装饰画面，不承担玻璃材质。内置预设以列表实际消费的纵向滚动量累计 `Long` 世界坐标；不能用通常为零的 `RecyclerView.scrollY` 或随加载量变化的滚动条估算值。每个列表独立对齐原点，稳定布局中第零项确实回到顶部才归零；布局过程和待处理更新中的临时 `canScrollVertically=false` 不能抹除滚动历史。列表从中途恢复时允许负坐标，避免快速回滑时锁死在零。云气和银河走向由非周期连续噪声取样，星点密度及流星数量、位置、角度、长度和粗细按世界区带使用固定种子随机生成；同一位置可稳定重建。相邻区带参与跨界光晕绘制，边缘额外取样避免过滤接缝。后台只生成可见区及前后一块，快速滚动时合并到最新视口，共享位图 LRU 上限 24 MiB；活跃列表另外持有当前窗口的区块，数量随视口而非滚动历史增长。星空、星云、流星固定为夜空配色，其他柔色预设保留主题适配；自定义图片继续使用原缩放与遮罩缓存。

启用壁纸的视频列表在绘制前还会清除加载更多尾项的独立换肤底色，让加载区域透出同一张背景。尾项须同时匹配直接子项 `loading` 进度条与 `tv_left`、`tv_right` 提示控件；仅清除容器背景，保留动画、提示和重试行为，不递归查找卡片或播放器的进度条。

星空、星云、流星通过 `HostBackgroundTheme` 临时覆盖宿主 `MultipleThemeUtils.getCurrentThemeId` 和 `isNightFollowSystem` 的读取结果，使宿主各页面统一使用原生深色主题。主进程和宿主子进程采用相同策略，不写宿主主题偏好；切换其他预设或关闭背景后，冷启动宿主即恢复原主题及跟随系统的选择。设置页的预览卡片同步使用深色配色，并说明主题恢复时机。相关实机回归覆盖三个夜空预设的标题对比度及普通预设、关闭背景后的主题恢复。

原生 `OpusDetailFragment` 图文详情以整页接入背景，`opus_dy_list` 的正文和段落间距共用壁纸原点。其装饰器通过 `gv1.c.s` 选择模块底色，仅在 Opus 装饰器、图文页面、非引用模块且未按压时透明化中性底色；保留装饰器本身、ItemOffsets、引用底色和业务色。`HostOpusChrome` 保留原生顶栏与底栏布局，以独立壁纸采样承托吸顶标题，并为底部操作栏使用静态表面。关注提示仍由宿主执行 61dp 进退动画，新增固定视口将绘制和触摸限制在底栏上方，不能依赖不透明底栏遮住退出中的提示。页面 detach 时释放表面并恢复提示的父容器和原参数。

## 个性主题装扮融合

开启宿主玻璃栏后自动使用纯粹融合策略：剥离首页搜索区和顶底栏的装饰底图，保留原生角色图标、SVGA 动画、角标、发布入口及下划线。清理在绘制前持续执行，防止异步图片回调和换肤只重设可见性时出现贴图遮挡。底栏启用时，个人中心立绘保留原图，在主视觉容器上使用底部圆角和渐变遮罩提高昵称及数据的可读性；容器同时包裹图片与原生视频装扮，不遮挡外层信息和操作按钮。

`HostGarbTheme` 优先读取 `GarbManager.getGarbWithNightMode(Context)`：夜间或夜空背景下 `getCurGarb()` 可能只返回纯黑皮肤，不能据此认定用户未装备装扮。强调色优先来自装扮选中色、其次为二级页面色；没有彩色字段时，在后台从宿主装扮目录的本地图片取色，透明像素和黑白边框不参与计算。纯色皮肤及缺失接口维持普通主题。日夜语义仍来自现有宿主主题，用户选择的壁纸保持独立。

玻璃及视频卡片表面混入 7% 装扮色，表面变体混入 9%，玻璃边缘采用提亮后的同色高光。分类标签使用对比度至少 4.5 的强调色；小底栏按可用高度等比缩小角色图标，移除装扮后恢复原尺寸。调色板在配色不变时复用，不在滚动帧解码图片或重复计算对比度。

个人中心主视觉使用独立硬件层，在视频与渐变合成后由 `HostGarbHeroForeground` 统一执行一次 `DST_OUT` 抗锯齿裁切；不分别对 TextureView 和前景应用 Outline 覆盖率，避免圆弧漏出细亮边。遮罩路径仅随尺寸变化更新，不读取视频帧或壁纸位图；离开装扮或释放绑定时恢复原有前景、轮廓、裁切与图层类型。真实窗口 PixelCopy 回归覆盖白色/黄色视频换帧、左右圆角的分数覆盖率、边缘无过亮像素及背后壁纸不被擦除。

## 顶栏与底栏材质配置

`HostChromeAppearance` 管理用户选择，`HostSurfaceStyle` 声明引擎参数，`HostSurfaceScope` 统一应用材质与后端；融合带也遵循所属顶栏的渲染选择。顶栏、底栏分别支持柔光透镜（默认，映射 FROSTED）与 Liquid（映射 LIQUID）。高级渲染提供自动（GPU 优先）和软件兼容。Liquid 的完整效果需要 API 33 与可用 GPU；软件兼容在 Liquid 下不可选，并保留切换前柔光的后端选择。导入 Liquid 到旧系统会回退为柔光。

旧配置和旧备份的隐藏 `legacy` 后端保留顶栏 AUTO、已启用底栏 SOFTWARE；首次新开启的栏选择 AUTO。界面第一次保存时写入明确选择，无需启动时批量改写用户偏好。合入主分支后新增四项设置属于目录 v45；已发布的 v44 保留 SponsorBlock 两项，可备份、导入、收藏定位，并随重启宿主生效。

普通胶囊 GPU 模糊恢复为原 RenderEffect 17dp，软件三重盒式模糊为 10dp；这是两种算法的等效强度映射，不是统一设成相同数字。两个材质使用同一组模糊声明，当前不开放滑杆。

柔光采样使用 `backdropOpacity = 1`，色罩保持原 112/120：模块 `FrostedMotionSurfaceAlpha.sampleAlpha` 在完整帧上归一化为 255，不能再把采样乘上 `(1 - tintOpacity)`。旧宿主单层合成遗留的这一乘法，会让浅色约 31% 的清晰底图从模糊层下面漏出，增大模糊半径也无法消除。Liquid 保留独立的清透采样比例；深色可读性控制只调整色罩，不覆盖调用方声明的采样透明度。

`HostChromeOpacityInstrumentedTest` 直接实例化模块完整柔光 renderer，以相同细条纹和文字对照宿主，覆盖浅色、深色可读性补偿和 Liquid 区分。额外底色色罩不能替代采样透明度归一化。该测试不写用户偏好，输出保存在忽略目录 `captures/lumen-1.2.0/opacity-20261008/`。`HostChromeRenderingInstrumentedTest` 的独立算法参照也使用模块实际的 255 采样 alpha。
