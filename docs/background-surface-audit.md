# 宿主背景覆盖层排查

核对版本：哔哩哔哩 8.90.2，versionCode 8902100。宿主 APK SHA-256：`804ab5d719da42f257aac6237dda408151b93ecff71a0da99c5f32c71161a2e5`。

## 扫描范围与证据

资源扫描解析 8,544 份布局，得到 643 个表面候选，涉及 619 类布局；另有一份解包 XML 因命名空间缺失未解析。候选仅表示需要检查，不能直接视为缺陷。

初版引用索引按双字节位置检查 DEX，可能把操作数、payload 当作指令。重新使用本机 JADX 所含 dexlib2 解码真实指令，遍历 2,056,205 个方法实现、25,422,179 条指令，得到 734 处布局引用，涉及 553 类候选布局。旧索引的 770 处引用及其推导出的消费者不能继续作为确认依据。

绑定类、DataBinderMapper 中的引用不等于可达入口。对确认项继续检查组件工厂、挂载服务、父子层次和页面清理代码，再通过回归验证。没有直接引用也不能证明布局不可达。

## 本轮确认并修复

| 对象 | 证据与触发条件 | 修复 |
| --- | --- | --- |
| 频道搜索建议 | `ChannelSearchActivity` 将结果 RecyclerView 和 `suggest_list` 放入同一个 `content_frame`。建议控制器只切换建议列表可见性；`n3` 仅上报页面可见性，没有隐藏结果。原规则清掉建议列表的整块背景。手机上清空搜索词后，底下“没有更多结果”的文字仍可见。 | 将有结果兄弟节点的建议列表识别为覆盖层，保留整块底板及其子树。仅同名、缺少父层或结果节点的普通列表不进入保护。 |
| 旧评论课堂、青少年模式遮罩 | `PrimaryCommentMainFragment.Yq/Zq` 将无根 id 的 NestedScrollView 追加到 `Po()`；其父类把 `Po()` 绑定到 `root_container`。遮罩的可点击、可聚焦内容块使用不透明中性底色，原规则会把它清空。 | 结合评论根的 `content/footer_container`、滚动包装、图片和关闭入口识别遮罩，保留其材质与控件；不修改宿主模式设置。 |
| 评论推送订阅及更多菜单 | `CommentPushDialogFragment`、`CommentPushMoreMenuDialogFragment` 使用独立 BottomSheet 根材质，但宽泛的 `Comment…Fragment` 名称匹配会把它们登记为评论正文并重铺背景。`CommentPushContainerFragment` 同属推送功能。 | 排除 `com.bilibili.app.comment3.push` 子树；保留 CommentV3 主页面、详情页、评论弹窗的正文适配。 |

前两项的新增结构回归在修复前均因背景从 ColorDrawable 变成 null 失败。修复后的验证包括完整底板像素、显隐切换、点击、关闭、页面归属，以及父结构不匹配时的反例。
